# QUBODecomposition.jl

Standalone local decomposition optimizer for the JuliaQUBO ecosystem.
This default-branch bootstrap establishes package identity; it contains no runtime optimizer.
Runtime implementation is developed on feature branches and reviewed in draft pull requests.

The package follows the [accepted design](https://github.com/JuliaQUBO/QUBO.jl/blob/7c3391f9e4ccf369027da858866f6d4b74790313/docs/src/design.md).
Accepting maintainer and release authority: [@bernalde](https://github.com/bernalde).
The intended first release is 0.1.0 through General registration, after the full MVP acceptance matrix and release checks pass.
No release or registration has been published.
